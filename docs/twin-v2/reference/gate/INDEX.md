# Reference set: the camp gate (P02a)

For comparison only (`QUALITY-BAR.md` section 8). None of these pictures is used as a texture. The open-web ones are from Wikimedia Commons under the licences shown and were fetched with `scripts/twin/reference/commons-fetch.mjs`; the owner's are in the git-ignored reference folder and are not copied here.

No photograph of the real camp gate has been supplied. The booth is therefore built in the camp's own building style, taken from the owner's photographs, and its layout (booth, boom, humps, signs) from ordinary Philippine site practice. **A photograph of the real gate would replace this.**
